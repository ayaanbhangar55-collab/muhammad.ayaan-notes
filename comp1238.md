# COMP1238 Notes

## Week 1 - History
- Computers have developed over time from early calculating devices.
- Data can be represented and stored in different ways.

## Week 2 - Bits and Bytes
- A bit is the smallest unit of digital data and represents 0 or 1.
- A byte consists of 8 bits.

## Week 3 - Data Representation
- Binary uses the digits 0 and 1.
- Computers use character encoding to represent text.

## Week 4 - The Internet and the Web
- The Internet is a global network connecting computers.
- A web browser lets users access websites.

## Week 5 - Web and Markdown
- Markdown uses symbols to format headings, lists, and links.
- GitHub repositories store files and track changes.
